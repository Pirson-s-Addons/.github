Loot-A-Rang Classic is a World of Warcraft addon for MoP Classic. Double right-click to use the Loot-A-Rang and loot from a distance. No bar slot.

What it does

Loot-A-Rang Classic uses the Loot-A-Rang toy for you: double right-click on the game world and the toy is used, so you can loot corpses from a distance without searching for it in your bags or bars.

Features

  • Double right-click (within 0.3 s) on the world uses the Loot-A-Rang.
  • Only out of combat.
  • Creates or updates a character macro called LootARangMacro (/use Loot-A-Rang) on login, in case you want it on a bar.
  • Uses the localized toy name, so it works on any client language (20 languages).

How to use

  • /lar on — enable the double right-click.
  • /lar off — disable it.
  • /lar help (or just /lar) — list the commands.
  • /lootarang works the same as /lar.

Installation

  1. Install it with the CurseForge app (recommended: it keeps the addon updated and puts it in the right client), or download the ZIP from the Files tab.
  2. If you install by hand, extract the LootARangClassic folder into World of Warcraft/<version>/Interface/AddOns/.
  3. Restart the game and make sure Loot-A-Rang Classic is enabled in the AddOns list.

Compatibility

Works on: MoP Classic · MIT License

Good to know

  • You need the Loot-A-Rang toy.
  • The on/off setting is not saved: the addon is enabled again every time you log in.

Loot-A-Rang Classic es un addon de World of Warcraft para MoP Classic. Doble clic derecho para usar el Loot-A-Rang y despojar a distancia. Sin ranura.

Qué hace

Loot-A-Rang Classic usa el juguete Loot-A-Rang por ti: haz doble clic derecho en el mundo y se usa el juguete, así despojas cadáveres a distancia sin tener que buscarlo en las bolsas o en las barras.

Funciones

  • Doble clic derecho (en menos de 0,3 s) en el mundo usa el Loot-A-Rang.
  • Solo fuera de combate.
  • Al entrar al juego crea o actualiza una macro de personaje llamada LootARangMacro (/use del juguete), por si la quieres en una barra.
  • Usa el nombre localizado del juguete, así que funciona con el cliente en cualquier idioma (20 idiomas).

Cómo se usa

  • /lar on — activa el doble clic derecho.
  • /lar off — lo desactiva.
  • /lar help (o solo /lar) — lista los comandos.
  • /lootarang funciona igual que /lar.

Instalación

  1. Instálalo con la app de CurseForge (recomendado: se actualiza solo y lo coloca en el cliente correcto) o descarga el ZIP de la pestaña Files.
  2. Si lo instalas a mano, descomprime la carpeta LootARangClassic en World of Warcraft/<versión>/Interface/AddOns/.
  3. Reinicia el juego y comprueba que Loot-A-Rang Classic está activado en la lista de addons.

Compatibilidad

Funciona en: MoP Classic · Licencia MIT

A tener en cuenta

  • Necesitas tener el juguete Loot-A-Rang.
  • El estado activado/desactivado no se guarda: el addon vuelve a activarse cada vez que entras al juego.
