Profession Reagents is a World of Warcraft addon for Retail, every Classic client and WoW Forever. Which professions use each reagent and at what skill, plus disenchant results.

What it does

Profession Reagents adds to the tooltip of every profession reagent the professions that use it and the skill levels where they do: from the first recipe you can learn to the last one that still gives skill points.

Copper Ore
Crafting Reagent
Mining                 1-70

Features

  • Every profession: Alchemy, Blacksmithing, Enchanting, Engineering, Jewelcrafting, Inscription, Leatherworking, Tailoring, Mining (smelting), Cooking and First Aid.
  • Data for your client: built from the game's own recipe tables for WoW Forever, Classic Era, TBC, Wrath, Cataclysm, Mists, Legion (also WoD), BfA, Shadowlands and Retail. In Retail each expansion line shows on its own (Classic Blacksmithing, Khaz Algar Blacksmithing...).
  • WoW Forever extras: what a green, blue or purple item gives when disenchanted (on enchanters, or for everyone with an option) and its average value with Auctionator; on dusts, essences and shards, which items give them; and when you hover an ore vein or herb, what it can give and how often.
  • Profession names in your game language, settings in the game's own Options → AddOns panel, 20 languages, no libraries.

How to use

  • Hover any reagent. That's it. If you know the profession, the range takes the game's difficulty colors for your skill: red = not yet, orange/yellow/green = useful now, gray = you're past it.
  • /preag opens the settings: turn the tooltip lines on or off, and show or hide the level range.

Installation

  1. Install it with the CurseForge app (recommended: it keeps the addon updated and puts it in the right client), or download the ZIP from the Files tab.
  2. If you install by hand, extract the ProfessionReagents folder into World of Warcraft/<version>/Interface/AddOns/.
  3. Restart the game and make sure Profession Reagents is enabled in the AddOns list.

Compatibility

Works on: Retail · WoW Forever · MoP Classic · Cataclysm Classic · Wrath Classic · TBC Classic · Classic Era · Legacy (WoD to Shadowlands) · MIT License

Good to know

  • The disenchant and gathering chances are the drop rates observed by Wowhead users, not official tables. Node tooltips work in every game language with GatherRadar installed; without it, only in English.
  • Retail recipes from Dragonflight on have no skill range in the game data (they use recipe difficulty instead): for them only the profession shows.

For addon authors

Public API

Read-only, versioned, always returns new tables. Add ## OptionalDeps: ProfessionReagents to your TOC. item is an itemID, an item link or a name (the name only if the client already knows the item).

local api = ProfessionReagentsAPI
if api and api.version == 1 then
    api.GetUses(2770)          -- { { skillLine, root, profession, min, max }, ... } or nil
    api.IsReagent("Copper Ore") -- true / false
    api.GetProfessionName(164) -- "Blacksmithing" in the client language
    api.GetReagentsFor(164, 50) -- { { itemID, skillLine, min, max }, ... } used at skill 50
end

skillLine is the profession line (164 Blacksmithing, 186 Mining...). In Retail every expansion has its own line and root says which profession it belongs to. min/max are nil when the recipes have no range.

Profession Reagents es un addon de World of Warcraft para Retail, todos los clientes Classic y WoW Forever. Qué profesiones usan cada componente y en qué nivel, y qué da al desencantar.

Qué hace

Profession Reagents añade a la ficha de cada componente de profesión las profesiones que lo usan y los niveles en los que lo hacen: desde la primera receta que puedes aprender hasta la última que aún da puntos.

Mineral de cobre
Componente de profesión
Minería                1-70

Funciones

  • Todas las profesiones: Alquimia, Herrería, Encantamiento, Ingeniería, Joyería, Inscripción, Peletería, Sastrería, Minería (fundición), Cocina y Primeros auxilios.
  • Datos de tu cliente: sacados de las tablas de recetas del propio juego para WoW Forever, Classic Era, TBC, Wrath, Cataclysm, Mists, Legion (también WoD), BfA, Shadowlands y Retail. En Retail cada línea de expansión sale aparte (Herrería clásica, Herrería de Khaz Algar...).
  • Extras en WoW Forever: qué sale al desencantar un objeto verde, azul o morado (si eres encantador, o para todos con una opción) y su valor medio con Auctionator; en polvos, esencias y fragmentos, de qué objetos salen; y al pasar el ratón por una mena o una planta, qué puede dar y con qué frecuencia.
  • Nombres de las profesiones en el idioma de tu juego, ajustes en el panel Opciones → Accesorios del propio juego, 20 idiomas, sin librerías.

Cómo se usa

  • Pasa el ratón por cualquier componente. Nada más. Si conoces la profesión, el rango sale con los colores de dificultad del juego según tu nivel: rojo = aún no, naranja/amarillo/verde = te sirve ahora, gris = ya te has pasado.
  • /preag abre los ajustes: activar o quitar las líneas de la ficha, y mostrar u ocultar el rango de nivel.

Instalación

  1. Instálalo con la app de CurseForge (recomendado: se actualiza solo y lo coloca en el cliente correcto) o descarga el ZIP de la pestaña Files.
  2. Si lo instalas a mano, descomprime la carpeta ProfessionReagents en World of Warcraft/<versión>/Interface/AddOns/.
  3. Reinicia el juego y comprueba que Profession Reagents está activado en la lista de addons.

Compatibilidad

Funciona en: Retail · WoW Forever · MoP Classic · Cataclysm Classic · Wrath Classic · TBC Classic · Classic Era · Legado (WoD a Shadowlands) · Licencia MIT

A tener en cuenta

  • Las probabilidades de desencantar y de recolección son las observadas por los usuarios de Wowhead, no tablas oficiales. Las fichas de los nodos funcionan en cualquier idioma del juego con GatherRadar instalado; sin él, solo en inglés.
  • Las recetas de Retail desde Dragonflight no traen rango de nivel en los datos del juego (usan la dificultad de la receta): en esas solo sale la profesión.

Para autores de addons

API pública

Solo lectura, versionada, siempre devuelve tablas nuevas. Añade ## OptionalDeps: ProfessionReagents a tu TOC. item es un itemID, un enlace o un nombre (el nombre solo si el cliente ya conoce el objeto).

local api = ProfessionReagentsAPI
if api and api.version == 1 then
    api.GetUses(2770)          -- { { skillLine, root, profession, min, max }, ... } o nil
    api.IsReagent("Copper Ore") -- true / false
    api.GetProfessionName(164) -- "Herrería" en el idioma del cliente
    api.GetReagentsFor(164, 50) -- { { itemID, skillLine, min, max }, ... } usados a nivel 50
end

skillLine es la línea de profesión (164 Herrería, 186 Minería...). En Retail cada expansión tiene la suya y root dice de qué profesión cuelga. min/max son nil si las recetas no traen rango.
