WoW Translator is a World of Warcraft chat translator addon: it translates every message in real time, right inside your chat window, into 44 languages. It understands MMO slang, raid callouts and trade abbreviations, and works on Retail, every Classic client and WoW Forever with one download.

Why WoW Translator

Playing on a realm full of French, German and Spanish speakers, joining an international guild or pugging Mythic+ with players from three countries? WoW Translator removes the language barrier so you can focus on the pull, not on the translation. No alt-tabbing, no copy-pasting into a browser.

It is built for World of Warcraft players: it recognizes MMO slang, raid terminology, trade abbreviations and everyday in-game expressions, the shorthand that generic translators turn into nonsense.

Example: LF1M tank M+ KSM link stays readable instead of becoming a word salad.

Features

  • Real-time translation: messages are translated instantly, inline in your chat window.
  • Built for WoW: understands raid callouts, dungeon terms, class abbreviations and trade slang.
  • 44 languages: full multi-language support, including regional variants.
  • Every chat channel: Say, Party, Guild, Raid and World.
  • Lightweight: no lag, no chat spam, no intrusive frames.
  • Easy to set up: a clean settings panel plus quick slash commands, and you can turn it on or off at any time.

Installation

  1. Install it with the CurseForge app (recommended: it keeps the addon updated and puts it in the right client), or download the ZIP.
  2. If you install by hand, extract the folder into World of Warcraft/<version>/Interface/AddOns/, for example _retail_, _forever_ (WoW Forever), _classic_era_ or _classic_.
  3. Launch the game and make sure WoW Translator is enabled in the AddOns list.
  4. Type /wt config to choose your language.

FAQ

Does it translate my own messages too?
It focuses on incoming chat so you understand what others say. Check /wt config for the available options.

Does it work on WoW Forever?
Yes, since v2.03, in the same download as every other version. Forever uses the modern interface, so everything works as on Retail: chat translation, Group Finder tooltips and the full settings panel.

Will it spam my chat?
No. Translations sit cleanly in the chat window and stay readable in raids and busy world channels.

Does it affect performance?
No noticeable impact on FPS: it is built to be lightweight.

Translations aren't showing up.
Turn them on with /wt on and run /wt test. If it still fails, please report it on GitHub.

I found a bad translation, or my language is missing.
Leave a comment or open an issue with the original message and the expected translation.

Preguntas frecuentes

¿También traduce mis propios mensajes?
Se centra en el chat entrante para que entiendas lo que dicen los demás. Revisa /wt config para ver las opciones.

¿Funciona en WoW Forever?
Sí, desde la v2.03, en la misma descarga que el resto de versiones. Forever usa la interfaz moderna, así que todo funciona igual que en Retail: traducción del chat, tooltips del Buscador de grupos y el panel de opciones completo.

¿Va a llenarme el chat de spam?
No. Las traducciones se integran de forma limpia y siguen siendo legibles en plena banda o en canales muy activos.

¿Afecta al rendimiento?
Sin impacto apreciable en los FPS: está pensado para ser ligero.

No me aparecen las traducciones.
Actívalas con /wt on y ejecuta /wt test. Si sigue fallando, repórtalo en GitHub.

He visto una traducción incorrecta, o falta mi idioma.
Deja un comentario o abre un issue con el mensaje original y la traducción esperada.
